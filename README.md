# Flask Project

This is a simple Flask-based web application built as part of my learning and practice.

Authentication
CRUD operations
REST API

## 🚀 Features
- User-friendly web interface
- Backend built with Flask
- HTML templates using Jinja2
- Static files support (CSS, JS)

## 🛠 Tech Stack
- Python
- Flask
- HTML, CSS
- SQLite (optional)

## ⚙️ How to Run Locally

1. Clone the repository
2. Create a virtual environment and activate it
3. Install dependencies:
   pip install -r requirements.txt
4. Run the app:
   python app.py

## 📌 Purpose
This project was built for learning Flask and demonstrating basic full-stack web development skills.
